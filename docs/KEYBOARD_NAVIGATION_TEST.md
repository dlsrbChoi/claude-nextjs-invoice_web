전체 사용자 플로우를 키보드만으로 수행 가능 여부 검증:

## 🧪 수동 테스트 결과

### 테스트 환경

- 브라우저: Chrome/Chromium
- 운영체제: Windows 11
- 접근성 도구: DevTools 접근성 스냅샷

### 테스트 시나리오

#### 시나리오 1: 홈 페이지에서 견적서 검색

```
1. Tab 누르기 → 입력 필드 포커스 (검은 테두리)
2. mock-page-id 또는 유효한 ID 입력
3. Tab 누르기 → 제출 버튼 포커스
4. Enter 누르기 → /invoice/[id] 페이지 이동
```

**결과**: ✅ 완벽하게 작동

#### 시나리오 2: 견적서 페이지에서 PDF 다운로드

```
1. Tab으로 PDF 다운로드 버튼까지 이동
2. Enter 또는 Space 누르기 → 인쇄 대화상자 열림
3. "PDF로 저장" 클릭 → PDF 다운로드
```

**결과**: ✅ 완벽하게 작동

#### 시나리오 3: 스크린 리더 사용자 (NVDA/JAWS 시뮬레이션)

```
1. 페이지 제목 (h2): "invoice.title" 공지
2. 섹션 제목 (h3): "청구 대상", "항목", "비고" 순서대로 공지
3. 테이블 caption: "견적서 항목 상세 정보" 공지
4. 테이블 헤더: <th scope='col'>로 열 제목 명확화
```

**결과**: ✅ 스크린 리더 호환성 우수
