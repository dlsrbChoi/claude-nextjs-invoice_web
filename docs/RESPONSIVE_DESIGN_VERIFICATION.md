## 🎯 TailwindCSS 브레이크포인트 확인

```javascript
// 현재 적용 중인 브레이크포인트
sm: 640px   (사용 안 함 - 모바일 우선)
md: 768px   (주요: 테이블/카드 전환)
lg: 1024px  (대형: 데스크톱)
xl: 1280px  (초대형)
2xl: 1536px (매우 큼)
```

**적용된 클래스**:

- `md:flex-row` - 768px 이상에서 가로 배치
- `md:block` / `md:hidden` - 테이블/카드 전환
- `md:px-4` - 패딩 조정
- `md:text-3xl` - 제목 크기 조정
